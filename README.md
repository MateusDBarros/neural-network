# Neural Network — From Scratch to Transformer

> **[🇧🇷 Versão em Português abaixo](#português)**

This repository documents a learning journey in AI, starting from a fully hand-rolled multi-layer perceptron and culminating in a GPT-style Transformer — all implemented in pure NumPy, without any deep learning frameworks.

The work led to a published mini-paper in the **TLC-BR (IBM Open Innovation Community)**:
**"GPT do Zero: Implementando um Modelo de Linguagem Transformer"**
📄 [`docs/GPT_do_Zero_TLC-BR_2026.pdf`](docs/GPT_do_Zero_TLC-BR_2026.pdf)

## GPT from Scratch — Key Results

| Metric | Value |
|---|---|
| Architecture | Decoder-only Transformer (GPT-style, pre-LayerNorm) |
| Parameters | 618,624 |
| Layers | 3 × Transformer blocks |
| Attention heads | 4 (d_head = 32) |
| d_model | 128 |
| Context length | 128 tokens |
| FFN hidden dim | 512 (4× multiplier) |
| Activation | GELU |
| Optimizer | AdamW (β₁=0.9, β₂=0.999, wd=0.1) |
| Training corpus | Portuguese literary texts (Machado de Assis, Fernando Pessoa, Guimarães Rosa) |
| Vocab size | 56 characters |
| Epochs | 200 |
| Initial loss | 3.6558 |
| Final loss | **0.0153** |
| Final perplexity | **1.0154** |

The model reached near-zero training loss, confirming the architecture and hand-written backpropagation are correct. The primary takeaway is that the model memorized the training corpus rather than generalizing — an expected outcome at this scale — and the natural next step is to explore regularization, larger and more diverse corpora, and generalization-oriented training strategies.

## Running

**Requirements:** Python 3.10+ and NumPy. No deep learning framework needed for `gpt/`.

```bash
# Smoke test — trains a tiny GPT and generates text
python gpt/gpt_numpy.py

# Full training run — writes reports/gpt_report.json
python gpt/run_report.py
```

For the neural network examples, `keras`, `torch`, and `torchvision` are also needed.

## Motivação

O objetivo não foi inventar algo novo, mas entender os fundamentos com profundidade suficiente para construir sobre eles. Implementar os gradientes de cada operação à mão — atenção multi-cabeça, LayerNorm, GELU, AdamW — força uma compreensão que frameworks como PyTorch ocultam.

Este é o primeiro passo de uma trajetória em pesquisa de IA. Os próximos trabalhos pretendem explorar abordagens mais avançadas com base no que foi aprendido aqui.

---

## Resultados Principais

O modelo atingiu loss de treinamento próximo de zero (**0.0153**, perplexidade **1.015**), confirmando que a arquitetura e a retropropagação manual estão corretas. O principal achado é que o modelo **memorizou** o corpus de treino em vez de aprender a generalizar — comportamento esperado nessa escala — e o próximo passo natural é investigar regularização, corpora maiores e estratégias orientadas à generalização.
